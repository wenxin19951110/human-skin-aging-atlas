# Human Skin Ageing Atlas
## Integrative Single-Cell and Spatial Transcriptomic Exploration of Human Skin Ageing

This repository documents an ongoing, self-directed computational research project investigating age-associated changes in human skin, with a focus on fibroblast–epidermal interactions and the tissue microenvironment.

### Computational Approach
This self-directed project uses Python, Scanpy, Pandas, and Matplotlib, with AI-assisted coding and debugging to support exploratory single-cell and spatial transcriptomic analyses. Biological interpretation, dataset limitations, and quality-control considerations guide the analytical workflow.

### Research Objectives

- Characterise fibroblast and epidermal cell populations using publicly available human skin scRNA-seq datasets.
- Explore age-associated changes in extracellular matrix, inflammatory and epithelial stem cell niche-related gene expression.
- Examine candidate fibroblast–keratinocyte interactions using spatial transcriptomic data.

### Current Progress

- Integration and visualisation of human skin single-cell datasets.
- Exploratory fibroblast and keratinocyte gene expression analysis.
- Candidate ligand–receptor and extracellular matrix analysis.
- MERFISH-based visualisation and exploratory assessment of spatial relationships.

### Project Status

**Work in progress.** Figures, analysis notebooks, documentation and reproducibility resources are being curated and added incrementally.

### Limitations

The current analyses are exploratory. Cohort and anatomical-site differences, limited donor numbers and targeted MERFISH gene coverage constrain age-related interpretation.
